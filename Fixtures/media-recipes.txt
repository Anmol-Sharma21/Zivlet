# One recipe per line: <file name> <hash|probe> <ffmpeg arguments>. `hash` files are compared with the committed
# manifest; `probe` files come from a hardware encoder that is not byte-stable, so only ffprobe opens them.
# Arguments are split on spaces (none contain one). generate.sh adds "-hide_banner -nostdin -loglevel error -y" in
# front and the bitexact flags, a fixed creation_time and the output path at the end.
